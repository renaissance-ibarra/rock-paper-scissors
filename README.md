# Rock Paper Scissors

A simple five-round, console-based Rock Paper Scissors game written in JavaScript.

## How to Play

1. Open `index.html` in a web browser.
2. Enter `rock`, `paper`, or `scissors` when prompted.
3. Play five rounds against the computer and view the final score in the browser console.

## Rules

- Rock beats scissors.
- Scissors beats paper.
- Paper beats rock.
- Matching choices result in a draw.

## Files

- `index.html` — Loads the game in a browser.
- `index.js` — Contains the game logic, scoring, and computer choice generation.
