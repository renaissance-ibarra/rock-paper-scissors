# Rock Paper Scissors

A browser-based Rock Paper Scissors game built with vanilla JavaScript. The player clicks one of the three choices, the computer makes a random move, and the round results are displayed in the page.

## How to Play

1. Open `index.html` in a web browser.
2. Click `Rock`, `Paper`, or `Scissors`.
3. The computer chooses randomly and a round result is displayed.
4. Scores update after each round.
5. The game ends when either the player or the computer reaches 5 points.
6. A winner is announced, then the score resets for the next match.

## Rules

- Rock beats scissors.
- Paper beats rock.
- Scissors beats paper.
- Matching choices result in a draw.
